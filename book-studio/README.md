# Book Studio

Part of the complete KindleWood website.
Keep this folder alongside the website's root index.html. Use ../#login to switch workspaces.

No build or dependencies required. Books and drafts are stored in this browser only.
AI output, login, and sharing are simulated. The demo does not create accounts or send messages.
Start over clears this studio’s demo data and opens its new-user home, without a recovery copy. Switch workspace returns to the role chooser and keeps the data.
